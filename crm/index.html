// SYSTEM SETUP

YAMATO CRM — 初期設定

Firebase Firestore でデータをチームで共有します。無料で運用可能。下記手順で5分ほどで設定できます。

1. 管理者から firebaseConfig（接続設定）を受け取ってください。
管理者は Firebase コンソール → ⚙️設定 →「全般」の「マイアプリ」で確認できます。
⚠ Firestore の「ルール」は管理者が設定済みです。絶対に書き換えないでください（書き換えると顧客データが外から見えるようになります）。
2. 下のテキスト欄にその config を貼り付けて「保存して開始」

Configはこの端末のブラウザにのみ保存されます
(他の端末で初めて開いた時はもう一度貼り付けが必要)
